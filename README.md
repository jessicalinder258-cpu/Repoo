# Paperlight

A private, browser-based PDF editor for annotating pages and exporting high-quality JPG images.

## Features

- Open PDFs locally without uploading them
- Draw, highlight, and add text annotations
- Rotate and navigate pages
- Export one page as JPG or every page in a ZIP
- Responsive editor interface

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
